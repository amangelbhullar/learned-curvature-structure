# Datasets

The experiments in this repository use six public knowledge graph benchmarks:

- WN18RR
- FB15k-237
- YAGO11k
- WIKIDATA12k
- ICEWS14
- GDELT

Controlled experiments additionally use synthetic branching, depth,
tree-likeness, planted-hierarchy, density, and degree-preserving graph
constructions.

Raw third-party benchmark datasets are not redistributed in this repository.
Users should obtain the datasets from their respective original sources.

Verified benchmark statistics used in the manuscript are provided under:

`results/datasets/paperA_dataset_counts_final.csv`

Derived relation-level structural statistics and learned curvature values
required to inspect the reported analyses are provided under `results/`.
